\# FleetTrack



FleetTrack is a Logistics \& Asset Management application designed to manage vehicles, drivers, trips, maintenance, fuel, expenses, assets, and related documents.



\## Project Goals



\- Manage fleet vehicles and assets

\- Manage drivers and assignments

\- Track trips and dispatch operations

\- Track vehicle maintenance

\- Manage fuel and operational expenses

\- Manage fleet-related documents

\- Provide dashboards and reports

\- Implement secure authentication and role-based access

\- Optimize MongoDB and SQL queries

\- Add automated testing

\- Implement GitHub Actions and CI/CD
